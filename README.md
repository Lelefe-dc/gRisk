# gRisk — Guardrisk Website Demo

Responsive static demonstration website for Guardrisk, based on the supplied company profile and Low Cost Medical Aid brochure.

## Demo features
- Responsive desktop, tablet and mobile layout
- Mobile bottom-tab navigation
- Company profile and professional services
- Basic Starter, Basic Saver and Basic Plus medical-aid sections
- Responsive plan comparison tables
- Hospital Cash Plan table
- Premium estimator
- Quote modal
- Phone, email and WhatsApp actions

## GitHub Pages
The demo is intentionally kept as a simple static site in `index.html` so it can be hosted directly from the `main` branch without a build pipeline.

In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save**.

Expected site URL: `https://lelefe-dc.github.io/gRisk/`

> Demo only. Plan information and quotations should be confirmed by Guardrisk before production use.
